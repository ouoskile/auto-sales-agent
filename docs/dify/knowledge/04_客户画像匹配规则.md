# 客户画像匹配规则（示例）

> 数据说明：本文件匹配规则基于《门店车型库》中的示例车型，仅用于演示推荐逻辑；正式使用时需随门店真实车型资料同步更新。

## 画像采集要素

推荐车型前先采集客户画像，至少覆盖预算、场景、人数、充电条件四项，意向车型为可选字段：

| 字段 | 含义 | 取值示例 | 采集方式 |
|---|---|---|---|
| budget | 预算区间 | 8 万以内 / 12–20 万 / 20 万以上 | 直接询问或从对话中提取 |
| scene | 主要用车场景 | 通勤 / 家用 / 商务 | 询问「主要家用还是通勤」 |
| family_num | 常坐人数 | 1–2 人 / 3–4 人 / 5 人以上 | 询问「家里几口人」 |
| charge | 是否有固定车位可装充电桩 | 是 / 否 | 询问「有没有固定车位」 |
| intend_car | 客户明确提到的意向车型 | 车型A / 车型B / 车型C | 从对话中提取，可为空 |

## 车型匹配规则

按预算、场景、人数、充电条件匹配车型，优先匹配预算与场景，再用充电条件和长途需求做二次筛选：

| 触发条件 | 推荐车型 | 匹配理由 |
|---|---|---|
| 预算 8 万以内、新手、市区代步 | 车型C（入门代步小车） | 车小好停、用车成本低、预算匹配 |
| 预算 12–20 万、家用带娃、通勤、看重续航 | 车型A（紧凑型家用 SUV） | 续航与空间兼顾，适合家庭通勤 |
| 预算 20 万以上、商务接待或二胎家庭、看重舒适底盘 | 车型B（中型商务轿车） | 轴距长、带空气悬架、乘坐舒适 |
| 看重省油、低用车成本 | 车型B（插电混动） | 插混兼顾油耗与长途，用车成本较低 |
| 经常长途、充电不方便 | 燃油 / 增程 / 插混车型（当前在售为车型B） | 避免纯电补能焦虑，适合长途 |
| 只城市通勤、有固定车位可装充电桩 | 纯电车型（车型A / 车型C） | 有桩条件适合纯电，用车成本低 |

## 匹配约束（必须遵守）

1. 画像不完整时先追问，不直接推荐车型；至少拿到预算和场景后再推荐。
2. 推荐必须对应《门店车型库》中真实存在的车型，不得编造车型、配置或参数。
3. 每次推荐 1–2 款，说明匹配理由，并主动说明不适合的点（例如预算超限、充电条件不满足）。
4. 预算明显超出在售车型范围时，如实说明并推荐最接近的车型，不硬推高价车。

## 画像不完整时的追问顺序

客户信息不足时，按「预算 → 场景 → 人数 → 充电条件 → 意向车型」的顺序逐项追问，一次最多问两个问题，避免连环追问：

- 预算："方便说下您的购车预算大概在什么区间吗？"
- 场景："平时主要用来上下班通勤，还是家用带家人出行？"
- 人数："家里常坐车的几口人？有没有小孩？"
- 充电条件："小区有没有固定车位，方便装充电桩吗？"
- 意向车型："您目前有看中的车型吗？我可以帮您对比。"
- 兜底：追问后仍无法确定预算或场景时，先给通用建议并邀请到店，由销售顾问补充画像。
