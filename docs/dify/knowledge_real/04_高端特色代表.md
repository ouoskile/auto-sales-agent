## 七、高端 / 特色代表品类（2 款）

### 蔚来 ES6

- **级别**：中型纯电 SUV
- **动力类型**：纯电动
- **指导价区间**：36.80-42.60 万元
- **核心参数**：轴距 2915mm，CLTC 续航 590-710km，换电技术，服务体系完善
- **核心卖点（FABE）**：
  - **F（特征）**：换电补能快，服务体系完善，豪华质感强，底盘调校优秀
  - **A（优势）**：换电 3 分钟和加油一样快，服务贴心，开着有质感
  - **B（利益）**：补能无焦虑，服务体验好，高端纯电的品质感拉满
  - **E（依据）**：国内高端新能源代表，换电模式独树一帜，用户忠诚度极高
- **目标客户画像**：高净值家庭、看重服务和品质、经常长途出行的高端纯电用户
- **对标竞品**：特斯拉 Model Y、宝马 iX3、小鹏 G9
- **销售沟通要点**：重点讲换电体验和服务体系，突出高端服务和品质感，适合看重服务的高端用户。

### 保时捷 Macan

- **级别**：紧凑型豪华 SUV
- **动力类型**：燃油 / 纯电
- **指导价区间**：57.80-85.30 万元
- **核心参数**：轴距 2807mm，2.0T / 高性能动力，保时捷操控，品牌力拉满
- **核心卖点（FABE）**：
  - **F（特征）**：保时捷入门 SUV，品牌力强，操控优秀，外观运动时尚
  - **A（优势）**：开出去有面子，操控好，品牌辨识度高，兼顾实用与个性
  - **B（利益）**：既能满足日常家用，又能享受保时捷的品牌和驾驶乐趣
  - **E（依据）**：豪华品牌最畅销的 SUV 之一，品牌认可度极高
- **目标客户画像**：高净值人群、年轻富豪、看重品牌和操控的豪华车用户
- **对标竞品**：宝马 X3、奔驰 GLC、奥迪 Q5L
- **销售沟通要点**：突出品牌、操控和外观，强调保时捷的品牌价值和驾驶乐趣，适合追求品牌和个性的用户。
