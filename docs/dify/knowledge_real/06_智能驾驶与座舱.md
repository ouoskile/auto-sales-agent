## 14. 智能驾驶分级（合规重写）

### 一、术语定义
智能驾驶分级采用 SAE 国际自动机工程师学会的官方标准，共分 L0 至 L5 六个等级，按系统对车辆动态驾驶任务的接管程度划分。需要特别说明：目前面向个人消费者量产销售的乘用车，最高普遍为 L2+ 级，均属于辅助驾驶范畴；L3 级仅少量车型在特定区域有限开放，L4、L5 仍处于示范运营或研发阶段。对外介绍相关功能时，统一使用「智能辅助驾驶」表述，不得简称为「自动」「无人」类词汇，并须强调驾驶员全程把控车辆。

### 二、各级别详细说明
#### 1. L0 级：无自动化
- 定义：完全由人类驾驶员操作，车辆没有持续的主动控制功能，仅提供提醒、警示。
- 包含功能：常规刹车、转向，以及车道偏离预警、盲区监测等提醒类功能。
- 核心特点：所有操作由人完成，车辆只提供信息提醒，不主动干预。
- 代表车型：老款低配车型、入门代步车。

#### 2. L1 级：驾驶辅助
- 定义：车辆能辅助驾驶员完成单一维度操作，要么控制速度，要么控制方向，两者不能同时持续控制。
- 核心功能：定速巡航（保持车速，驾驶员控制方向）；车道保持辅助（轻微修正方向，驾驶员控制车速）。
- 核心特点：单功能辅助，驾驶员仍是操作主体。
- 市场现状：当前在售车型多以 L2 起步，纯 L1 车型较少。

#### 3. L2 级：组合驾驶辅助（对外统一称「L2 级智能辅助驾驶」）
- 定义：系统可同时控制车速与方向，实现横向与纵向的组合辅助，但驾驶员必须全程监控路况、双手不离方向盘，随时准备接管。
- 核心功能：ACC 自适应巡航（纵向控制车速、跟车）；LCC 车道居中保持（横向控制方向）；AEB 自动紧急制动；自动泊车辅助。
- 核心特点：可减轻驾驶疲劳，但人是主导、系统是辅助；驾驶员必须手握方向盘、全程关注路况；复杂路况与突发情况仍需人工处理。
- 市场现状：目前主流车型的辅助驾驶级别，10 万元以上车型普遍配备。
- 合规销售话术：「这是 L2 级智能辅助驾驶系统，高速和拥堵路况能帮您减轻驾驶疲劳，不用一直踩油门刹车；但手不能离开方向盘，仍需您全程把控车辆安全。」

#### 4. L3 级：有条件驾驶自动化
- 定义：在特定设计运行条件下（如高速、封闭道路），系统可承担动态驾驶任务，驾驶员无需持续监控，但在系统发出接管请求时必须在规定时间内接管。
- 核心特点：特定场景下系统主导驾驶，驾驶员角色转为「安全员」；事故责任界定更复杂，具体以法律法规与厂家条款为准。
- 市场现状：国内已有少量车型在特定路段开放 L3 级功能，普及度低、使用场景有限。
- 合规注意：L3 级对外同样使用「智能辅助驾驶」或「有条件驾驶自动化」表述，不得使用「自动」「无人」类简化说法；驾驶员在系统请求接管时仍须及时接管。

#### 5. L4 级：高度驾驶自动化
- 定义：在特定区域、特定条件下，系统可完成全部驾驶任务，无需驾驶员接管，车辆可以不设方向盘。
- 应用场景：封闭园区、港口、矿区、特定城市区域的无人接驳与无人出租车。
- 现状：以商用及特定场景示范运营为主，乘用车量产普及仍有较长距离。

#### 6. L5 级：完全驾驶自动化
- 定义：全场景、全路况下无需人工驾驶，车辆不设方向盘、油门、刹车，乘员全程为乘客。
- 现状：仍处于研发与法规探索阶段，距离量产落地较远。

### 三、L2+ 级是什么？
- 定义：行业俗称，指在基础 L2 功能之上增强的高阶辅助驾驶方案，法规等级本质仍为 L2 级智能辅助驾驶。
- 核心增强功能：NOA 导航辅助驾驶（按导航路线辅助超车、变道、上下匝道，驾驶员需监控）；城市道路辅助（市区道路辅助跟车、路口通行、避让行人，驾驶员需随时接管）；记忆泊车、代客泊车辅助。
- 注意：无论功能多强，只要仍需驾驶员全程监控，就仍是 L2 级智能辅助驾驶，不得宣传为「自动」或「无人」类功能。

### 四、销售合规红线（必须严格遵守）
1. 禁止使用夸大或误导性表述（如声称车辆可自行驾驶、双手可离开方向盘、驾驶员可休息等），统一称「智能辅助驾驶」。
2. 必须主动说明：系统为辅助属性，驾驶员必须全程把控车辆安全，双手不离方向盘。
3. 不得夸大功能：不得宣称「能自动避让所有障碍物」「市区不用管了」，必须说明系统局限性，复杂路况需人工接管。
4. 高速、高架场景可以说「减轻驾驶疲劳」，不得说「双手可以离开方向盘」。
5. 安全性能以官方公布信息为准，不做结果性承诺。

### 五、客户常见疑问合规解答
1. 问：这车能自己开吗？
   答：这款车是 L2+ 级智能辅助驾驶，能在高速和快速路上辅助跟车、保持车道，帮您减轻驾驶疲劳；但它不是「自动」驾驶，需要您全程手握方向盘、关注路况。
2. 问：上了高速是不是就不用管了？
   答：不是的，系统只是辅助，遇到施工、匝道、恶劣天气等复杂路况仍需您及时接管；它能帮您省力，但不能替代您驾驶。
3. 问：出了事故算谁的？
   答：辅助驾驶状态下，驾驶员仍是车辆安全第一责任人，因此必须全程关注路况、随时准备接管；具体责任认定以交警部门与法律法规为准。
4. 问：L2 和 L3 有什么区别？
   答：L2 需要驾驶员全程监控并随时接管；L3 在特定设计运行条件下由系统承担驾驶任务，但系统请求接管时必须及时响应。目前国内在售车型主流仍是 L2 级智能辅助驾驶。

### 六、销售实战注意事项
1. 合规是底线，虚假宣传辅助驾驶功能，客户发生事故时门店需承担相应责任。
2. 主动说明系统局限性，反而显得专业可信，客户更信任。
3. 重点讲「减轻疲劳」「提升安全」，不讲双手离开方向盘、无需人工操作等表述。
4. 试驾演示时，务必提醒客户双手不要离开方向盘，做好正确示范。
5. 所有功能名称、适用条件以厂家官方用户手册与配置表为准，不过度解读。

## 15. 辅助驾驶功能

### 一、术语定义
辅助驾驶功能是L2级智能驾驶的具体功能模块，核心作用是减轻驾驶疲劳、提升行车安全，按场景分为高速辅助、城市辅助、泊车辅助三大类，是目前车型智能化的核心卖点。

### 二、巡航与跟车类功能
#### 1. 定速巡航（CCS）
- 定义：设定一个车速，车辆自动保持该速度行驶，不用踩油门。
- 适用场景：高速、路况好的畅通道路。
- 优势：解放右脚，减轻长途驾驶疲劳。
- 劣势：遇到前车减速需要自己踩刹车，不能自动跟车。
- 定位：最基础的巡航功能，入门车型配备。

#### 2. ACC自适应巡航
- 定义：在定速巡航基础上，增加雷达监测前车距离，自动跟车，前车快就快，前车慢就慢，前车停就停。
- 核心优势：
  1. 高速不用频繁踩油门刹车，大幅减轻疲劳。
  2. 市区拥堵也能自动跟车，堵车不累。
- 分类：
  1. 全速域ACC：0-150km/h都能用，堵车也能跟停，是目前主流。
  2. 普通ACC：30km/h以上才能用，低速用不了。
- 销售话术：
  “高速开ACC，脚就不用一直踩着油门刹车了，轻松很多；市区堵车也能自动跟车，前车走就走，前车停就停，堵车再也不累了。”

#### 3. IACC智能巡航
- 定义：ACC+车道居中保持结合，同时控制车速和方向，是L2级辅助驾驶的核心。
- 适用场景：高速、高架、快速路等封闭道路。
- 体验：车辆自己保持在车道中间，自己跟车，驾驶员只需要扶着方向盘，盯着路况。

### 三、车道控制类功能
#### 1. LDW车道偏离预警
- 定义：车辆无意识偏离车道线时，通过声音、震动提醒驾驶员。
- 特点：只提醒，不干预，属于L1级功能。
- 作用：防止疲劳驾驶跑偏。

#### 2. LKA车道保持辅助
- 定义：车辆偏离车道时，自动轻微打方向，把车拉回车道内。
- 特点：被动修正，跑偏了才拉，不是一直居中。
- 作用：辅助保持车道，降低跑偏风险。

#### 3. LCC车道居中保持
- 定义：通过摄像头识别车道线，让车辆一直保持在车道中央行驶，主动控制方向。
- 特点：主动居中，不是跑偏了才修正，行驶更平顺。
- 地位：L2级辅助驾驶的核心横向控制功能。
- 注意：只能识别清晰的车道线，车道线模糊、施工路段会失效。

#### 4. ALC自动变道辅助
- 定义：打转向灯后，系统监测侧后方路况，安全的话自动完成变道。
- 适用场景：高速、高架封闭道路。
- 优势：变道更安全、更轻松，不用自己把控方向。

### 四、导航辅助驾驶（NOA）
- 定义：高阶辅助驾驶功能，按照导航路线行驶，自动完成超车、变道、上下匝道、进出服务区。
- 分类：
  1. 高速NOA：只在高速、高架能用，是目前主流。
  2. 城市NOA：城市普通道路也能用，能过红绿灯、避让行人和非机动车。
- 核心优势：长途高速几乎不用自己操作，只需要监控路况，大幅减轻驾驶负担。
- 销售话术：
  “设定好导航，上了高速它自己开，超车、变道、下匝道都自动完成，您只需要扶着方向盘盯着就行，开长途特别轻松。”
- 注意：还是L2级辅助驾驶，必须驾驶员全程监控，随时接管。

### 五、主动安全类功能
#### 1. AEB自动紧急制动
- 定义：监测前方车辆、行人、非机动车，有碰撞风险时，先报警提醒，驾驶员没反应就自动刹车。
- 作用：避免或减轻追尾、鬼探头事故，是最实用的安全配置之一。
- 分类：
  1. 车辆AEB：只能识别车辆。
  2. 行人AEB：能识别行人、非机动车。
  3. 交叉路口AEB：路口左转、横穿场景也能识别。
- 销售话术：
  “市区开车万一有行人突然窜出来，您没反应过来，车会自动帮您刹停，能避免很多事故，特别实用。”

#### 2. 前向碰撞预警（FCW）
- 定义：监测前方车距，太近有碰撞风险时，发出提醒。
- 特点：只提醒，不自动刹车，是AEB的前置功能。

#### 3. 后方交叉路口预警（RCTA）
- 定义：倒车出库时，监测侧后方来车，有碰撞风险时提醒，甚至自动刹车。
- 作用：车位两边有车遮挡视线时，特别有用，避免倒车剐蹭。

### 六、泊车辅助类功能
#### 1. 倒车影像+倒车雷达
- 定义：倒车时显示后方画面，雷达探测障碍物距离，滴滴提醒。
- 地位：最基础的泊车辅助，现在基本所有车都有。

#### 2. 360度全景影像
- 定义：车身前后左右多个摄像头，合成车辆周围的全景鸟瞰画面。
- 作用：低速行驶、停车时，周围没有盲区，能看到路沿、石墩、小孩。
- 销售话术：
  “360全景特别实用，窄路会车、停车的时候，周围都看得清清楚楚，不用担心刮蹭，新手也能停好车。”

#### 3. APA自动泊车
- 定义：车辆自动识别车位，自动控制方向、油门、刹车，完成泊车入库。
- 支持车位：垂直车位、侧方车位、斜列车位。
- 作用：新手友好，停车困难户福音。
- 销售话术：
  “侧方停车停不好没关系，按一下自动泊车，车自己就停进去了，比人停得还准。”

#### 4. AVP代客泊车
- 定义：记忆固定停车场的路线，车辆可以自己进停车场、找车位、泊车，还能召唤车辆到门口接人。
- 特点：驾驶员不用在车上，车辆自主完成泊车。
- 限制：只能在记忆过的停车场用，陌生停车场不行。

### 七、销售实战注意事项
1. 讲功能一定要结合场景，比如“高速开ACC不累”“市区堵车跟车解放右脚”“新手停车用自动泊车”，客户更容易感知价值。
2. 必须说明功能局限性：
   - 车道线模糊、施工、暴雨大雾天气，辅助驾驶会失效。
   - AEB不是万能的，速度太快、障碍物太小也可能识别不了。
3. 不要夸大功能，越客观客户越信任，买回去也不会有落差。
4. 一定要给客户演示、试驾体验，辅助驾驶功能光说没用，开一次就知道有多香。
5. 重点突出安全和轻松两个核心价值，家庭用户看重安全，经常跑高速的看重轻松。

## 16. 智能座舱

### 一、术语定义
智能座舱是车内智能化交互与体验的总称，包含车机系统、语音交互、显示系统、舒适配置等，是客户日常用车接触最多的部分，也是车型差异化体验的核心卖点。

### 二、座舱硬件术语
#### 1. 座舱芯片
- 定义：车机系统的核心处理器，相当于手机的SOC芯片，决定车机的流畅度、多任务能力、AI算力。
- 主流型号：
  1. 高通骁龙8155：目前主流旗舰芯片，7nm工艺，算力强，流畅度高，20万以上车型普遍配备。
  2. 高通骁龙8295：新一代旗舰芯片，5nm工艺，算力更强，支持多屏联动、更复杂的AI功能，高端车型使用。
  3. 联发科、地平线等国产芯片：性价比高，中低端车型使用。
- 核心指标：算力、制程工艺，数值越高性能越强。
- 销售话术：
  “用的是高通8155芯片，和旗舰手机同款，车机特别流畅，滑动、打开应用都不卡，用五六年也不会像老车机那样卡顿。”
- 客户常见疑问：
  问：芯片重要吗？
  答：特别重要，就像手机芯片一样，芯片差的话，用两年就卡了，体验很差；好芯片用很多年都流畅。

#### 2. 屏幕配置
- 中控屏：中间的主控屏幕，控制车机功能，尺寸普遍10-15英寸。
- 全液晶仪表：替代传统机械仪表，显示车速、导航、辅助驾驶信息，尺寸10-12英寸。
- 副驾娱乐屏：副驾专属屏幕，看视频、听音乐，高端车型配备。
- 后排娱乐屏：后排头枕屏幕，给后排乘客娱乐用，商务、高端家用车型配备。
- 屏幕素质：分辨率、刷新率、亮度，越高显示效果越好，阳光下也能看清。

#### 3. HUD抬头显示
- 定义：将车速、导航、辅助驾驶等信息，投射到前挡风玻璃上，驾驶员不用低头看仪表。
- 分类：
  1. W-HUD：普通抬头显示，投射信息少，面积小。
  2. AR-HUD：增强现实抬头显示，投射面积大，能将导航箭头、预警信息叠加在真实道路上，体验更好。
- 核心优势：
  1. 不用低头看仪表，视线不离开路面，更安全。
  2. 科技感强，体验高级。
- 销售话术：
  “开车的时候不用低头看仪表，导航、车速都在前挡风上，视线一直看着路，更安全，而且科技感特别强。”

#### 4. 流媒体后视镜
- 定义：通过车尾摄像头，将后方画面实时显示在后视镜上。
- 核心优势：
  1. 视野是传统后视镜的3倍，没有盲区。
  2. 不受后排乘客、行李遮挡。
  3. 雨天、夜间视线比传统后视镜好。
- 劣势：需要适应，看屏幕和看实物距离感不同。

### 三、车机系统与交互
#### 1. 车机系统类型
- 原生安卓系统：基于安卓定制，开放性好，能装APP，功能丰富，是主流方案。
- 鸿蒙座舱：华为鸿蒙系统，流畅度高、多设备联动强、生态好，是目前体验第一梯队。
- CarPlay/CarLife：手机互联，将手机画面投射到车机上，适合车机不好用的车型。
- 自研系统：车企自研系统，比如特斯拉、比亚迪DiLink、小鹏Xmart OS。

#### 2. 语音交互系统
- 定义：通过语音控制车机功能，是最常用的智能交互方式。
- 核心指标：
  1. 唤醒速度：越快越好，好的系统一秒以内响应。
  2. 识别准确率：方言、噪音环境下也能准确识别。
  3. 连续对话：说一次唤醒词，能连续发多个指令，不用每次都唤醒。
  4. 可见即可说：屏幕上显示的内容，直接说文字就能操作，不用记指令。
  5. 四音区识别：能区分主驾、副驾、后排位置，谁说话响应谁，比如后排说“打开天窗”，不会误操作主驾。
- 可控制功能：导航、音乐、空调、车窗、天窗、座椅调节等几乎所有车内功能。
- 销售话术：
  “语音特别好用，开车的时候不用动手，说一声就能开空调、导航，更安全也更方便，还支持连续对话，不用每次都喊唤醒词。”

#### 3. 多屏联动
- 定义：中控屏、仪表、副驾屏、后排屏之间可以联动，比如中控把导航划到仪表，副驾把视频投到后排。
- 优势：体验流畅，科技感强，方便车内成员交互。

### 四、舒适配置术语
#### 1. 座椅相关
- 座椅通风：座椅里有风扇，夏天散热，后背屁股不闷汗，南方夏天必备。
- 座椅加热：冬天座椅变暖，北方冬天实用。
- 座椅按摩：座椅里有按摩气囊，长途开车缓解疲劳，高端车型配备。
- NAPPA真皮：高端真皮材质，触感细腻柔软，档次感高。
- 座椅记忆：保存不同驾驶员的座椅位置，换人开车一键恢复，不用重新调。
- 零重力座椅：模仿太空零重力姿态，身体压力均匀，久坐不累，主打舒适性。

#### 2. 空调与空气系统
- 分区自动空调：主驾、副驾、后排可以分别设置温度，每个人调自己舒服的温度。
- 热泵空调：新能源车用，比传统PTC加热省电，冬季续航衰减少。
- 车载空气净化器：过滤PM2.5、异味，保持车内空气清新。
- 负离子发生器：产生负离子，净化空气，提升空气质量。

#### 3. 其他舒适配置
- 全景天幕/全景天窗：车顶大面积玻璃，车内通透不压抑，档次感强。
- 双层夹胶隔音玻璃：玻璃中间夹胶，隔音效果好，车内更安静，高速体验提升明显。
- 主动降噪系统：通过音响发出反向声波，抵消噪音，提升车内静谧性。
- 电动尾门：后备箱电动开关，不用手动抬，手上拿东西方便。
- 感应尾门：脚踢一下后备箱底部，自动开门，手上拿满东西的时候特别实用。
- 车载冰箱：车内冰箱，冷藏饮料、药品，高端车型配备。

### 五、销售实战注意事项
1. 智能座舱是最容易让客户“种草”的部分，一定要现场演示，语音控制、360全景、座椅功能都演示一遍，体验感拉满。
2. 讲配置要结合客户痛点：南方客户重点讲座椅通风，北方客户讲座椅加热，经常跑高速讲ACC和座椅按摩。
3. 不要堆配置名词，要讲客户能获得的好处，比如“座椅通风”要说“夏天开车后背不闷汗，特别舒服”，不要只说“有座椅通风”。
4. 芯片、系统这些硬件，重点讲“流畅、不卡顿、用好几年都好用”，客户关心的是使用体验，不是参数。
5. 科技配置不是越多越好，适合客户的才重要，比如中老年客户可能不需要复杂的语音、副驾屏，简单好用更重要。
